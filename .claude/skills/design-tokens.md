# design-tokens

- Palette:
  - `ink`: `#1a1a2e`
  - `surface`: `#16213e`
  - `accent`: `#e94560`
  - `text`: `#eaeaea`
  - `muted`: `#8892b0`
  - `success`: `#64ffda`
  - `border`: `#0f3460`
- Typography:
  - Display/headings: `Space Grotesk`
  - Commands, code, terminal: `IBM Plex Mono`
- Motion:
  - Use a few meaningful staged reveals.
  - Terminal lines can animate in sequence.
  - Avoid generic floating blobs or constant idle animations.
- Surfaces:
  - Prefer rounded glass panels with subtle borders and deep shadows.
  - Keep the background layered with gradients and a faint grid texture.
- Product framing:
  - Never imply Claude is the primary source or target.
  - Sources and targets should receive equal visual weight.
